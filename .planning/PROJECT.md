# Wallhaven 壁纸浏览器 - 性能与架构优化

## What This Is

Wallhaven 壁纸浏览器是一个基于 Electron + Vue 3 的跨平台桌面应用，用于浏览和下载 Wallhaven.cc 网站的壁纸。

本次里程碑聚焦于**性能优化、代码质量提升和架构债务清理**，在不改变任何用户可见功能的前提下，优化内部实现质量。

## Core Value

**性能优先，质量为本。** 在严格保持功能兼容性的前提下，系统性优化代码质量、性能表现和架构清晰度。

## Context

### 技术环境

- **Electron**: 41.2.2 + Vue 3.5.32
- **架构**: 严格分层（Views → Composables → Services → Repositories → Clients）
- **状态管理**: Pinia 3.0.4
- **数据持久化**: SQLite (Node.js 内置)
- **构建工具**: electron-vite 5.0.0 + Vite 7.3.2

### 已识别的问题

详细问题清单见 `.planning/codebase/CONCERNS.md`，本次聚焦：

1. **性能瓶颈**：高频 IPC 更新、缓存策略简单、批量查询未优化
2. **代码质量**：错误处理混乱、类型分散、缺少取消机制
3. **架构债务**：职责不清、状态分散、命名不一致

### 脆弱区域

修改以下区域需格外小心：

- **下载队列系统**：状态同步复杂，并发控制敏感
- **收藏功能**：SQLite 外键约束，多组件使用
- **状态管理**：Service 缓存与 Store 状态同步

## Constraints

- **兼容性**: 所有现有功能必须保持完全一致的行为
- **架构约束**: 遵循现有分层架构（Views 禁止直接导入 stores）
- **技术栈**: 不引入新的核心依赖（除 lru-cache 等轻量工具库）
- **提交策略**: 原子提交，每个逻辑变更独立提交
- **测试验证**: 每个优化点必须有手动或自动测试验证
