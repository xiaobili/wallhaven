## Context Notes

### 里程碑目标

- 将在线壁纸页面和收藏页面从传统分页改为虚拟列表
- 实现无限滚动加载
- 使用 vue-virtual-scroller 库
- 保留所有现有功能（多选、hover交互、搜索筛选）

### 技术决策

1. **虚拟列表库**: vue-virtual-scroller（Vue 生态最成熟）
2. **加载方式**: 无限滚动（滚动到底自动加载）
3. **状态保持**: 不保持滚动位置（简化实现）

## Memory

### Decisions Made

1. **vue-virtual-scroller**: Vue 3 生态最成熟的虚拟列表库

3. **功能保留**: 不影响用户已习惯的多选、hover、筛选功能
