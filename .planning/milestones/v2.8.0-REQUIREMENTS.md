# Requirements Archive: v2.8.0 性能与架构优化

**定义日期:** 2026-05-06
**归档日期:** 2026-05-06
**核心价值:** 性能优先，质量为本 — 在严格保持功能兼容性的前提下，优化内部实现质量

---

## v1 Requirements — 全部完成 ✅

### Performance (性能优化)

- [x] **PERF-01**: 下载进度 IPC 更新频率优化 ✅
  - 将更新间隔从 100ms 调整为 300ms
  - 实现节流机制
  - 验证 UI 响应性未受影响
  - **结果**: IPC 调用频率降低 66%

- [x] **PERF-02**: 壁纸搜索缓存策略改进 ✅
  - 实现基于内存占用的 LRU 缓存
  - 添加缓存命中率监控
  - 保持现有 API 不变
  - **结果**: 使用 lru-cache，50MB 内存限制，5 分钟 TTL

- [x] **PERF-03**: 收藏状态批量查询优化 ✅
  - 实现前端收藏状态缓存
  - 使用增量更新策略
  - 减少数据库查询次数
  - **结果**: 收藏状态缓存迁移到 FavoritesStore

- [x] **PERF-04**: 图片尺寸解析可靠性提升 ✅
  - 使用 sharp 库替代手动解析
  - 修复 WebP 格式解析问题
  - 保持错误处理一致
  - **结果**: 支持 WebP、AVIF、TIFF 等格式

### Quality (代码质量)

- [x] **QUAL-01**: 统一错误处理格式 ✅
  - 所有 IPC handler 使用 IpcErrorInfo 类型
  - 统一错误码和消息格式
  - 利用现有 AppError 错误类体系
  - **结果**: 创建 IPC_ERROR_CODES 常量和 createErrorResponse 辅助函数

- [x] **QUAL-02**: 消除类型定义重复 ✅
  - 统一 DownloadProgressData 定义位置
  - 统一 CacheInfo 定义位置
  - 更新所有引用点
  - **结果**: 类型统一定义在 src/types/ipc.ts

- [x] **QUAL-03**: 异步操作取消机制 ✅
  - 为关键异步操作添加 AbortController 支持
  - 在 Vue composables 的 onUnmounted 中清理
  - 防止内存泄漏和竞态条件
  - **结果**: 壁纸搜索支持取消，组件卸载时自动清理

- [x] **QUAL-04**: 配置值集中管理 ✅
  - 创建统一的配置模块
  - 移除硬编码的魔法值
  - 保持可配置性
  - **结果**: src/config/constants.ts 包含所有配置

### Architecture (架构优化)

- [x] **ARCH-01**: 服务层职责边界明确化 ✅
  - 定义 Service 层职责：业务逻辑 + 错误转换
  - 定义 Repository 层职责：数据访问 + 持久化 + IPC 封装
  - 创建 download-task.repository.ts
  - **结果**: DownloadService 不再直接使用 electronClient

- [x] **ARCH-02**: 状态管理统一化 ✅
  - 将 Service 缓存迁移到 Pinia Store
  - 实现单一数据源原则
  - 简化状态同步逻辑
  - **结果**: 所有状态统一在 Store 管理，Service 无状态化

- [x] **ARCH-03**: IPC 通道命名规范化 ✅
  - 统一使用 kebab-case 命名
  - 更新所有 IPC 通道定义
  - 保持向后兼容（已统一，无需迁移）
  - **结果**: 验证 IPC_CHANNELS 常量已统一使用 kebab-case
